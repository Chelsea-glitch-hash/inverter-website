## 二、分类整理

### 第一类：全品类品牌型（Deye / Growatt / GoodWe / SolaX / SOFAR）

**共性打法**：
- 导航用「解决方案（Solution）」而非「产品（Product）」组织 —— 先讲客户场景，再推产品
- 首页堆数据锚点（出货量、在线台数、发电量、专利数、国家数），建立"大厂"心智
- 新闻/展会/认证持续更新，给 GEO 引擎提供"持续活跃、可信赖"的信号
- 每个产品系列独立 SEO title（品类词 + 认证词 + 功率参数词）

**适合本站**：这些站的"解决方案页 + 数据锚点 + 新闻更新"三件套，是 zzpine.com 从"产品目录站"升级为"制造商品牌站"的直接模板。

---

### 第二类：离网 / DIY 性价比型（MPP Solar / SRNE / MUST）

**共性打法**：
- 深耕细分品类词（off-grid inverter、inverter charger、MPPT controller），不跟头部拼品牌词
- 用工具型内容（选型指南、系统配型、教程视频）服务 DIY/批发商，换取社区口碑与反向链接
- 多 SKU 系列化命名（PIP-LV/PIP-MS、DM/MEH/MES、PH1100…），关键词矩阵做深做透
- 全球分销伙伴地图 / 当地办事处清单，解决"跨境售后"信任问题

**适合本站**：本站主产品正是离网逆变器，这一类是同赛道直接竞品 —— 它们的**关键词矩阵结构和工具型内容**应逐条对照落地。

---

### 第三类：混合储能新锐（LuxPowerTek）

**共性打法**：
- 用「数字锚点 + 具体收益的案例研究」在缺乏品牌历史时建立信任
- 认证安装商查询页（Certified Installer），把渠道伙伴变成询盘分发网络
- 新品类词精准卡位（hybrid inverter + 三相/单相 + 地区后缀 EU/US）

**适合本站**：案例研究（德国住宅 / 越南工厂）的写法 —— **地点 + 装机量 + 自用率 + 年收益**四要素 —— 应直接复用到本站的 case 页。

---

### 第四类：内容营销标杆（Enphase）

**共性打法**：
- 把"客户决策旅程"拆成 9 大章节的教育内容矩阵（Solar A to Z：为什么装 → 原理 → 选型 → 成本 → 安装 → 使用 → 升级），每一章都是长尾关键词页
- B2B2C：先教育安装商/渠道，再通过渠道触达终端，内容同时服务两类人群（homeowners + installers）
- 内容页大量 FAQ + 结构化问答，专为 AI 摘要（GEO）设计

**适合本站**：本站博客仅 2 篇，Enphase 的内容矩阵结构（how it works / sizing / cost / install / maintain）正是博客扩充的骨架。
