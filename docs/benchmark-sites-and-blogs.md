## 内容打法总结：7 条可直接复用的规律

1. **「功耗/参数百科」关键词矩阵**是品类流量基本盘
   `How many watts does X use` · `What can a XXXXW power station/inverter run` · `How long will X last`
   代表：BLUETTI、Pecron、VTOMAN

2. **场景落地页 > 产品列表页**
   每个场景（RV / Tiny House / Farm / Off-Grid Cabin / Balcony Solar / Home Backup）一个独立 URL，从导航二级菜单进入。代表：Renogy、EcoFlow、Zendure

3. **工具化内容带来高质量外链与停留**
   功率计算器、系统选型器、电池兼容性查询。代表：Renogy Calculator、PowerGetup Calculators、Sunsynk 知识库

4. **真实项目案例是 B2B 最强信任背书**
   Victron 全部内容都是用户故事；EG4 / Sunsynk / Renogy 都有 Case Study 栏目。**这一点对你（B2B 出口）价值最高**——海外经销商看的就是"你给谁装过、装在哪"

5. **知识库 / 论坛从主站拆到独立域名**
   `community.jackery.com` · `forum.renogy.com` · `support.sunsynk.com`。好处：主站不被海量内容稀释权重，知识库可独立做 SEO

6. **认证与合规本身就是一个内容品类**
   UL 1741 / UL 9540 / IEC 62109 / CE / 各国并网规范，做成独立内容页 → 直接承接 B2B 采购的合规审查需求。EG4、Sol-Ark、Sunsynk 都在打这张牌

7. **品牌三方对比由内容站承接，品牌站自己只做规格对比表**
   品牌站不做 `vs` 攻击性内容（避免争议），改为在自家产品页放**结构化规格对比表**——这同时服务 AI 引擎抓取（表格是 AI 最喜欢的引用格式）
